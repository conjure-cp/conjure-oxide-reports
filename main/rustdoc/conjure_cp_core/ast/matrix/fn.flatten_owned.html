pub fn flatten_owned<T: MatrixValue>(
    matrix: AbstractLiteral<T>,
) -> impl Iterator<Item = T>
Expand description

Consumes a multi-dimensional matrix and returns a one-dimensional slice of its elements. The elements are returned in row-major ordering (see enumerate_indices).

§Panics

  • If the number or type of elements in each dimension is inconsistent.
  • If matrix is not a matrix.
