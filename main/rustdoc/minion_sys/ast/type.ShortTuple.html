A short tuple — used by short-tuple constraints (shortstr2, haggisgac, haggisgac-stable, shortctuplestr2). Each entry is a (variable_index, value) literal; the position refers to the constraint’s variable list. For shortstr2 / haggisgac / haggisgac-stable the indexes within one short tuple must be distinct (the propagators reject duplicates). shortctuplestr2 allows multiple entries for the same index (OR semantics within that short tuple).
